Fight system

The Strike Grammar: one hit, six beats

Every attack uses the same beats. Each beat tells the character, the camera, the sound and the light what to do, so these four layers always land together. The times are the decisive blow in Ganryūjima.

Sound

Find, check, place

Find. Each cue is a line in the film file with search words. engine/sound.mjs searches Openverse (free CC0 and CC-BY sounds).

Check. Candidates are measured with ffmpeg. Silent, too-quiet or too-short files are rejected, and leading silence is trimmed.

Place. The engine already knows when every slash and step happens, so each sound starts at its cue time. Beds loop; everything is mixed and limited under the video.

CC-BY sounds need the author's name in the video description. The list is in assets/sfx/CREDITS.md.

{
  "id": "impact",

  "min": 200, "max": 4000,   // ms length window
  "len": 1.5,           // seconds used
  "gain": 1.0           // loudness
}

Prompt
Work in the repo blackadmen732-wq/papi.
Read AGENTS.md first, then docs/CAMERA.md, docs/STYLE-AND-FIGHT-SYSTEM.md and docs/playbook.html.

Make a new Lantern Origami film, 30–40 seconds, about: [YOUR STORY HERE].

Follow the playbook steps in order:
1. Research the history. Write research/<name>.md, marking each fact documented / tradition / our choice.
2. Copy film/ganryujima.json to film/<name>.json. Write the shots (camera keyframes), titles, shakes and sound cues.
3. Pick characters, outfits and swords from library/ (add presets there if needed).
4. Write the choreography with the 6-beat Strike Grammar (hit-stop on every hit).
5. Check still frames with node engine/render.mjs --film film/<name>.json --still ... and fix the framing before any full render.
6. Render, then run node engine/sound.mjs --film film/<name>.json.
7. Rebuild the playbook: python3 docs/build_playbook.py film/<name>.json
Rules: never start a paid GPU without asking me first and stating the cost. Commit and push when done.
House rules

What keeps the look and the budget safe

  1. Check stills before renders. A still takes seconds; a full 36-second render takes about 55 minutes on CPU.
  2. Paid GPUs need the owner's yes first, with the cost. Use the cheapest community GPU, set the 60-minute self-destruct timer, and stop the pod before any wait. An idle pod once cost $3.
  3. Free compute first: this machine, then Kaggle (free GPU after phone verification).
  4. Light means power: amber glow for people, crimson for demonic power and impacts. Paper shards, never blood.
  5. History is marked honestly. Tradition is never presented as documented fact.
  6. Commercial-safe licences only (MIT, Apache, CC0, CC-BY), and CC-BY sounds are credited.
  7. No secrets in files. API keys are injected by the network proxy.
